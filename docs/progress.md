## 8. 教学规范

### Day 01–77

- 不安排理论问答。
- 不安排选择题、判断题或填空题。
- 不安排面试模拟。
- 不要求背诵 Java 八股文。
- 通过编程、测试、运行结果和项目实操完成验收。

### Day 78–90

集中进行理论问答、算法、项目答辩和模拟面试。

### 日常教学流程

知识讲解 → 示例演示 → 独立实操 → 提交代码 → 代码检查 → 提示修改 → 正式验收。

### 文件管理

- 每天创建独立练习目录。
- Markdown 文件由导师提供完整内容。
- Markdown 正文不需要提交检查。
- 代码及运行结果需要提交正式验收。
- 每天完成后生成交接记录。
- 每天使用新的学习会话。
- 正式项目持续迭代，不重复创建。
